## 🛠️ Ferramentas CLI & Runtime

### 1. **Modernizadores do `go fix`** ⭐⭐⭐⭐

#### O que é?
Novas ferramentas de refatoração automática para modernizar código Go:

- **`atomictypes`**: Otimiza operações com tipos atômicos (atomic)
- **`embedlit`**: Refatora literals de `embed.FS` para sintaxe mais moderna
- **`slicesbackward`**: Moderniza operações em slices para usar APIs mais novas
- **`unsafefuncs`**: Refatora código `unsafe` para alternativas mais seguras

#### Aplicação no mqd-client?
✅ **SIM - Alto Impacto**

**Por quê:**
- Projeto usa `sync.Mutex` e possíveis operações atômicas em monitoramento
- Pode ter código legacy que se beneficiaria da modernização

**Como usar:**
```bash
# Executar refatoração específica
go fix -fix=atomictypes ./...
go fix -fix=slicesbackward ./...
go fix -fix=unsafefuncs ./...

# Verificar mudanças antes de aplicar
go fix -fix=slicesbackward -dryrun ./...
```

**Arquivos afetados:**
- `application/message_process_Worker.go` (usa sync.Mutex)
- `crosscutting/monitoring/metrics.go` (monitoramento com possíveis operações atômicas)
- Estruturas de fila e processamento de mensagens

### 3. **`go mod tidy` com Estrutura Consolidada** ⭐⭐⭐⭐

#### O que é?
Organização automática e consolidação de blocos `require` no `go.mod`:

```go
// ANTES (pode ter duplicatas e desordenação)
require (
    github.com/golang-jwt/jwt/v5 v5.3.1
    go.opentelemetry.io/otel v1.46.0
)
require (
    github.com/prometheus/client_golang v1.24.1
)

// DEPOIS (consolidado automaticamente)
require (
    github.com/golang-jwt/jwt/v5 v5.3.1
    github.com/prometheus/client_golang v1.24.1
    go.opentelemetry.io/otel v1.46.0
)
```

#### Aplicação no mqd-client?
✅ **SIM - Já Aplicado!**

**Status:**
- ✅ Já executado durante atualização para Go 1.27.1
- `go mod tidy` consolidou automaticamente as dependências
- go.mod agora está mais limpo e organizado

**Benefício:**
```bash
# Antes (com nossos updates):
# - Múltiplos blocos require
# - Possível desorganização

# Depois:
# - Um único bloco require organizado
# - Mais fácil de revisar em PRs
# - Menos conflitos em merge
```

**Como manter:**
```bash

# Automatizar em pre-commit hooks
echo "go mod tidy" >> .git/hooks/pre-commit
```

### 5. **Detecção de Leaks no `runtime/pprof`** ⭐⭐⭐⭐⭐

#### O que é?
Perfil `goroutineleak` agora **Generally Available (GA)** para detectar goroutines bloqueadas permanentemente:

```go
import "runtime/pprof"

// Usar em testes
func TestForLeaks(t *testing.T) {
    // Código do teste
    
    // Verificar goroutines ao final
    profile := pprof.Lookup("goroutine")
    if profile.Count() > expectedCount {
        t.Errorf("goroutine leak detected: %d goroutines", profile.Count())
    }
}
```

#### Aplicação no mqd-client?
✅ **SIM - Crítico Para Este Projeto**

**Por quê:**
- Projeto tem goroutine em `metrics.go` (startMemoryCalculator)
- Usa workers de processamento de mensagens em fila
- Gerencia múltiplas conexões e managers

**Implementação recomendada:**

1. **Em Testes (Unit Tests):**
```go
// crosscutting/monitoring/monitoring_test.go
package monitoring_test

import (
    "runtime/pprof"
    "testing"
    "time"
    
    "github.com/OpenBanking-Brasil/MQD_Client/crosscutting/monitoring"
)

func TestMetricsNoGoroutineLeaks(t *testing.T) {
    initialCount := runtime.NumGoroutine()
    
    // Executar código que usa metrics
    // ...
    
    // Aguardar cleanup
    time.Sleep(100 * time.Millisecond)
    
    finalCount := runtime.NumGoroutine()
    if finalCount > initialCount {
        profile := pprof.Lookup("goroutine")
        t.Logf("Goroutine profile:\n%s", profile)
        t.Errorf("goroutine leak: %d -> %d goroutines", 
            initialCount, finalCount)
    }
}
```

2. **Em Profiling de Produção:**
```go
// Adicionar em seu pprof setup
import _ "net/http/pprof"

// Acessar via HTTP
// curl http://localhost:6060/debug/pprof/goroutine
// curl http://localhost:6060/debug/pprof/goroutine?debug=1
```

3. **Arquivos a Atualizar:**
- `application/queue_manager.go` - Verificar lifecycle de goroutines
- `crosscutting/monitoring/metrics.go` - Garantir cleanup da goroutine
- `application/message_process_Worker.go` - Verificar workers

**Benefício:**
- 🔍 Detecta goroutines bloqueadas ou "órfãs"
- 📊 Identifica memory leaks relacionados a goroutines
